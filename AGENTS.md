# Instrucciones para agentes

Este proyecto usa **[CLAUDE.md](CLAUDE.md)** como archivo de instrucciones, y
sirve igual para Claude, Gemini, Copilot o cualquier otro agente. Léelo antes de
tocar el código.

Lo más importante, para que no se pase por alto: **LukApp se maneja por
versiones en formato `V0.0.0`**. Mira la versión actual en
[`src/version.ts`](src/version.ts), súbela con **todo** cambio por pequeño que
sea, y di en qué versión quedó cada vez que entregues algo.
