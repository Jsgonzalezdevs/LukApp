# Biblioteca de conocimiento para el Asesor de LukApp

Estos archivos están preparados para el panel **Conocimiento de LukApp para la IA** del superadmin. La carga acepta PDF, TXT o Markdown de hasta 4 MB por archivo; el Markdown es el formato fuente recomendado para mantener títulos y listas claros.

## Paquete

| Archivo | Tema del panel | Para qué sirve |
|---|---|---|
| `00-general-asesor.md` | General | Criterios de conversación, precisión, seguridad y límites. |
| `01-uso-de-lukapp.md` | Uso de LukApp | Navegación, movimientos y funciones disponibles. |
| `02-finanzas-personales-colombia.md` | Finanzas | Orientación educativa sobre presupuestos, ahorro, deudas, GMF e inversiones. |
| `03-importacion-y-extractos.md` | Importación y extractos | Formatos, pasos de revisión y tratamiento de filas bancarias. |

## Carga recomendada

Adjunta cada `.md` por separado y selecciona el tema indicado. Cada documento queda como borrador. Comprueba que la vista previa extraída conserve el texto y luego actívalo. La biblioteca busca fragmentos relacionados con cada pregunta, así que los documentos se escribieron con encabezados y términos que una persona puede usar en sus consultas.

Los documentos describen la versión **v10.14.12** (13-11-2026). Cuando cambien pantallas o reglas del producto, vuelve a revisar las rutas y capacidades antes de reemplazar los archivos. Las recomendaciones tributarias y bancarias requieren verificación de fuentes vigentes.
